# Skills

Reusable agent skills.

## Included skills

- [`syn`](syn/SKILL.md) — compress a difficult abstract structure into a precise sensory model.

## Install

Install into the default Agent Skills directory:

```bash
./install.sh
```

Install into another skills directory:

```bash
./install.sh --dest /path/to/skills
```

Use `--force` to replace an existing `syn` installation.
